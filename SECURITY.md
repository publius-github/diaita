# Security policy

Diaita is an offline-first app: it has no backend, no accounts and stores all data
on the device. The only network use is the optional OpenFoodFacts lookup.

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/publius-github/diaita/security/advisories/new)
rather than in a public issue. Include the app version, Android version and steps to
reproduce. You can expect an initial reply within a few days.

Only the latest release is supported.
